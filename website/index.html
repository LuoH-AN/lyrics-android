完整使用指南
需要换播放器吗？

不需要。播放器需通过 Android MediaSession 提供歌曲信息和播放进度。不同播放器、系统与版本的行为可能不同，不保证全部兼容。

支持什么设备？

需要 Android 8.0 及以上、64 位 ARM 设备和可用的 Android System WebView，无需 Root 或 LSPosed。目前不提供 iOS、32 位 ARM 或 x86 安装包。

为什么要通知使用权？

用于访问播放器公开的媒体会话，读取歌曲信息、封面和进度。当前实现不处理通知正文，也不通过麦克风录音识曲。它与普通“允许发送通知”不同；悬浮显示还需要悬浮窗权限。

每首歌都有歌词和逐字效果吗？

不保证。内容与可用性取决于歌词源，来源名称不代表官方合作。普通 LRC 按整句显示，逐字高亮需要逐字时间轴。“双语显示”不会自动开启机器翻译。

匹配不对或小窗消失怎么办？

可在歌词源管理中查看候选，或导入 LRC；整体提前或延后可调整偏移。主页与小窗对手动固定版本的使用仍有差异。小窗消失时，检查悬浮窗权限和本应用的后台省电限制，部分系统界面也会限制悬浮显示。

会把什么信息发到网络？

查词、封面与别名匹配会向歌词平台或 Apple iTunes Search API 发送歌曲信息，检查更新会访问 GitHub。自定义 LRC 文件保存在本机。

补充翻译默认关闭。启用 API 翻译后，待译文本（也可能来自自定义 LRC）会发送到你配置的服务，并可能产生费用。离线语言包的下载、更新和兼容性检查会联网，ML Kit 可能发送性能与使用指标。

查看权限与联网说明

网页演示是真实播放器效果吗？

不是。演示使用原创示例文案，非真实歌曲歌词，也不读取设备上的音乐。仓库截图由应用界面渲染，不代表跨播放器实测；实际表现取决于设备、播放器和歌词源。

项目来自哪里？

由 LuoH-AN 继续开发，最初来自 Tcrrrry 的 desktop-lyrics。上游及第三方代码保留原有声明，各部分许可详见仓库。
