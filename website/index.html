BEFORE YOU START / 用之前

你可能
想先知道。

完整使用指南 ↗
需要换播放器吗？支持哪些播放器？+

不需要换。「桌面歌词」读取播放器公开的 Android MediaSession。播放器需要提供歌曲信息和播放进度；不同播放器、系统与版本的行为可能不同，目前不做“全部兼容”的承诺，也不列未经实测的兼容清单。

需要 Root 吗？为什么要通知使用权？+

无需 Root 或 LSPosed。通知使用权用于访问播放器的媒体会话，读取歌曲信息、封面和进度；当前实现不处理通知正文，也不通过麦克风录音识曲。通知使用权与普通“允许发送通知”不同；悬浮窗权限则用于把歌词显示在其他应用上方。

每首歌都有歌词、翻译和逐字效果吗？+

不保证。效果依赖歌词源的内容与时间轴：普通 LRC 按整句显示，逐字高亮需要逐字时间轴。“双语显示”不会自动打开机器翻译；补充翻译需要你主动启用。

找错歌词、不同步或者小窗消失怎么办？+

匹配不对时可以在歌词源管理中查看候选、导入 LRC；整体提前或延后可调整偏移。主页与小窗对手动固定版本的使用仍有差异，详见使用文档。小窗消失时检查悬浮窗权限与本应用的后台省电限制；部分系统界面本身也会限制悬浮显示。

会把什么信息发到网络？+

查词、封面与别名匹配会向歌词平台或 Apple iTunes Search API 发送歌曲信息，检查更新会访问 GitHub。自定义 LRC 文件保存在本机；主动启用 API 补充翻译后，缺少译文的文本（也可能来自自定义 LRC）会发送到你配置的服务。离线翻译的语言包下载、更新及兼容性检查也会联网，ML Kit 可能发送性能与使用指标。查看详细说明 ↗
