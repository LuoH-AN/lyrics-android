# 桌面歌词

简洁的 Android 桌面歌词应用，由 [LuoH-AN](https://github.com/LuoH-AN) 维护。

[下载正式版](https://github.com/LuoH-AN/lyrics-android/releases/latest) · [反馈问题](https://github.com/LuoH-AN/lyrics-android/issues)

</div>

让歌词跟着音乐，出现在你想看的地方。通过原生 Material 界面和桌面悬浮小窗，同步显示正在播放的歌词；支持逐字高亮、双语显示、自定义歌词，以及字号、颜色和背景调整。不需要额外账号，配合你常用的音乐播放器即可使用。

## 开始使用

1. 下载并安装最新版本 APK。
2. 按提示授予通知使用权和悬浮窗权限。
3. 播放音乐，点击主页中控台「⋯」左侧的歌词图标开启小窗；具体调整在「⋯ → 设置」里。

需要 Android 8.0 及以上、64 位 ARM 设备和 Android System WebView。播放器需提供标准 MediaSession；如小窗被系统清理，请放宽应用的后台省电限制。
