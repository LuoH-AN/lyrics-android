# 歌词外观与双语显示

## 字号、粗细和背景

入口：主页中控台 **⋯ → 设置 → 悬浮窗外观**。

- **歌词粗细**：300–900，数值越大越粗；与字号独立保存。Android 8 的系统字体可用字重较少，相邻档位可能接近。
- **歌词预览**：与实际小窗共用原生渲染，字号、粗细、上下文及翻译模式同步生效。预览里的英中歌词仅是样例。
- **透明**：不绘制背景，直接透出下方页面；实际小窗则透出桌面或其他应用。
- **半透明**：叠加一层半透明深色背景。
- **不透明**：深色背景完全不透底。没有额外灰色外框。

歌词不叠加文字阴影、光晕或描边。透明模式下，浅色字放在浅色背景上对比度较低；可以调整歌词颜色，或选择半透明／不透明背景提升可读性。

## “双语”与“补充翻译”有什么区别？

在 **设置 → 歌词与翻译 → 外语歌词** 中：

| 模式 | 显示内容 |
| --- | --- |
| 原文 | 只显示原歌词 |
| 双语 | 原歌词下方显示对应译文 |
| 中文 | 有译文时显示译文；缺译文时保留原文 |

**选择“双语”不会自动启用机翻。** 歌词源已有的译文可以直接显示，不需要配置翻译服务。没有译文时，仍会显示原文，而不是凭空生成中文。

## 缺少译文时怎么做？

进入 **设置 → 歌词与翻译 → 补充翻译**，选择一种补充方式：

1. **离线翻译**：先下载歌曲语种与中文所需的语言包，再启用离线方式。语言包下载需要可用网络，完成后翻译不需要向 API 发送歌词。
2. **API 翻译**：配置服务地址、模型和密钥并验证配置，再启用该方式。缺译文的歌词会发送到你选择的服务，可能产生服务费用。

返回主页即可应用，无需重启或重新开启小窗。主页和悬浮窗都支持补充译文；平台已有的译文优先保留，只补缺少的行。已经是中文、没有歌词或尚未下载所需语言包时，不会出现预期之外的“双语结果”。

如果仍然只有原文，请先查看翻译状态：补充方式是否关闭、是否缺少语言包、API 是否配置完整、网络请求是否失败。不要把“选中双语显示”当成“翻译服务已准备好”。
