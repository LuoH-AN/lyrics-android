# 歌词外观与双语显示

## 主页歌词

入口：主页中控台 **⋯ → 设置 → 主页歌词**。1.3.0 新安装默认居中，原文基准字号 28 sp、译文 17 sp、字重 500、行间距 10 dp；已有保存值继续优先使用。可调整原文字号、翻译字号、字重、行间距和对齐方式，并查看文字预览；封面模糊背景默认关闭，可手动开启，开启后用铺满页面的封面图、柔和模糊与暗色遮罩衬托浅色歌词。原文字号为 16–48 sp，翻译字号为 12–32 sp，字重有细体到特粗六档，行间距为 0–28 dp。

在 **歌词显示模式** 中选择「滚动」或默认的「逐词跃动」。逐词跃动受 Folia 的逐词动画启发，当前句的词随演唱逐个跳出，按屏幕尺寸均衡断行，优先保留词组、标点和停顿位置，减少过长行与过短尾行；三种排版的短句都居中，错落和阶梯采用较小的偏移。点当前句可重听，长按仍可摘句分享。显示模式在设置中直接选择，舞台不再放置浏览或返回按钮。

逐词跃动需要歌词源的逐字时间轴。只有逐行 LRC、译文与原文文字不一致或逐字数据不匹配时显示整句，不估算演唱时间；纯文本歌词沿用滚动列表。特别长的句子限制独立动画数量，舞台显示整句并在必要时省略，完整正文保留在摘句分享中，也可在设置中切换为滚动模式查看。双语译文紧跟歌词下方，减少歌词与译文之间的空白。镜头默认根据当前词的位置连续运动，转换为围绕中心的轻微倾转与呼吸缩放；歌词整体保持居中；封面背景保持稳定，切换封面时平缓淡化；开启系统或应用的「减少动效」时，显示稳定的当前句。

语义分组使用手机系统自带的分词能力识别词边界，结合标点与实际停顿规划换行，每个字仍按歌词源提供的时间跳出。下一句会提前准备测量与排版；快句自动缩短过渡，极短句直接显示。

逐词跃动选中后，会显示专用自定义选项：逐词／逐字入场、错落／居中／阶梯／波浪／随机排版、多向移入／向上移入／缩放入场／四向聚合／中心扩散／随机入场、入场时长、提前量、入场位移、当前词缩放、旋转、镜头方式与幅度、呼吸缩放以及整句切换方式。另外可调整词组内与词组间距、行距倍率、行宽比例、错落幅度、跟随速度、整行动效、高亮保持与已唱不透明度，也可开关语义分组、动态间距与时长自适应。每项独立保存，也可保存为动效方案。「恢复推荐方案」同时恢复动效与文字样式。新安装默认采用「均衡流动」：错落、多向移入、420 ms 入场、90 ms 提前量、100% 距离、145% 当前词缩放、10° 旋转、80% 跟随幅度、开启呼吸与轻微缩放切换。逐字选项把一个有时间轴的词拆为完整字符后依次弹出；各字符保留词的真实起止时间，细小错位仅用于入场编排，未编造逐字演唱时间。

1.3.5 的逐词跃动默认按真实词组和停顿拆成短语，每段默认约 10 个中文字，可通过「短语长度」调整。短段分别适配字号，下一段进入时上一段淡出腾出空间；「行宽比例」同步影响分段容量。长音增加可调的「长音振幅」。没有真实逐词时间的内容继续整句显示。

主页歌词设置提供「实时预览」，使用与主页相同的文字渲染，示例包含快句、长音和换段。点击卡片内「固定」可在调节下方参数时保持预览可见；支持暂停和重播。离开设置、切到后台或预览移出屏幕时停止播放。

整句与短语切换共用淡入淡出、滑动、缩放、四向聚合、四向扩散和随机效果，运动围绕歌词中心展开。滑动与随机切换可另选左、右、上、下、左右随机、上下随机或四向随机推移。随机效果根据歌词内容和时间稳定选择，同一句不会因刷新、暂停或拖动进度重新抽取。入场使用柔和起步、轻微回弹和完整收尾，整行位移与逐词入场减少重复运动。

镜头提供固定、漂移、跟随文字和环绕跟随。漂移独立于呼吸开关，以中心倾转呈现；相邻句子延续镜头速度，长间奏逐渐收敛。波浪排版沿行形成起伏，随机排版按句选择，已有间距、行宽比例和错落幅度继续生效。

「动效协调」新增三个独立开关和一项力度选择：

- **强调力度**：轻柔、均衡、强烈。调整放大、旋转、飞入、长音和镜头的整体力度，各项细调数值继续保存。
- **节奏自适应**：默认开启。密集起唱减少放大、旋转与入场位移，较长的词和长音保留更舒展的表现；同时起唱的字使用相同的节奏判断。
- **动效协调**：默认开启。文字优先，整行、镜头与转场在多种强动效同时开启时自动收敛；新句或短语落稳后平滑恢复；横屏和大字体占满空间时，先收敛动效，再适配字号。
- **转场联动**：默认开启。缩放、聚拢和散开沿镜头走势带少量位移，随机推移参考镜头方向；手动指定左、右、上、下始终生效。镜头固定或停止时使用稳定的歌词种子选择。

整句切换现在与逐词、短语和镜头共用播放时间。暂停冻结当前转场，变速同步调整视觉进度，拖动进度能还原对应位置；旧句只在有限的淡出窗口内绘制。译文与对应原句一起进入、退出，切句时不会直接跳成新字幕。

「舞台留白」可调画面占比（65–100%，默认 94%）、水平留白（8–40 dp，默认 20 dp）、译文间距（4–28 dp，默认 10 dp）和译文行数上限（1–4，默认 3）。歌词使用可用画面的中心，取消垂直偏移和固定的短语放大上限。短语排版比较不同断行方案，按实际文字尺寸与屏幕宽高选择字号；少字和两行歌词优先放大占屏，原文字号作为测量基准。错落、阶梯、波浪和随机排版都将整体文字边界居中。入场时新词的边界随淡入逐渐参与居中计算，避免突然跳位。双语模式按实际译文高度保留空间，主歌词仍位于画面中心；字幕宽度限制在便于阅读的范围，长译文按允许行数换行或省略。特别小的预览与大字体组合会按可用高度适配，换段后的字幕位置平滑收拢，避免与仍在淡出的高段落重叠。

「动效方案」提供 9 套内置方案，每套包含动效和文字排版。推荐默认为「均衡流动」：原文 28 sp、译文 17 sp、字重 500、行间距 10 dp，镜头跟随和动效协调开启。升级保留已有参数，选择「恢复推荐方案」才会重置动效和文字样式。

| 方案 | 显示特点 | 原文 / 译文字号 |
| --- | --- | --- |
| 均衡流动（推荐） | 错落排版，平滑跟随 | 28 / 17 sp |
| 静阅 | 居中排版，低幅动效 | 30 / 18 sp |
| 轻柔 | 轻缓上移，柔和淡入 | 28 / 17 sp |
| 波形 | 波浪排版，纵向转场 | 28 / 17 sp |
| 环绕 | 缓速环绕，缩放转场 | 30 / 17 sp |
| 横向推移 | 阶梯排版，左右转场 | 28 / 17 sp |
| 中心聚合 | 四向聚合，向外散出 | 30 / 17 sp |
| 节奏 | 快速入场，强化重音 | 28 / 17 sp |
| 自由变换 | 随机排版，多向转场 | 28 / 17 sp |

内置方案不占用户方案额度。自定义方案最多保存 12 套，包含全部跃动参数及字号、译文字号、字重和行间距。应用后继续调节不会修改已保存的副本；同名保存可覆盖。方案不包含配色、翻译方式或封面背景开关。

播放栏支持完整、紧凑和仅圆形封面三种形态，去掉底板和边框，竖屏恢复原宽度且不额外限高；横屏只限制左右宽度，完整栏占据上下可用高度，内部控件居中成组。上滑依次展开圆形、紧凑、完整，下滑依次收起，横屏高度会跟随手势平滑变化；中等栏左滑缩到左下角封面，右滑把封面送到右下角。左侧封面向右滑、右侧封面向左滑，可拉回紧凑栏；长按也可展开。点封面暂停或继续播放，圆环显示进度。横竖屏使用相同手势，每次进入横屏默认缩成右下角圆形，返回竖屏恢复竖屏原来的大小与停靠方向。

主页「更多 → 沉浸观赏」隐藏状态栏、导航栏及播放控件，让歌词使用整个可用区域。轻触歌词或空白处显示控制，正在播放时 4 秒后收起；拖动控制或打开更多菜单时保持可见，暂停时不自动收起。沉浸时轻触歌词用于唤出控制，长按仍可分享；返回键或右上「退出沉浸」恢复普通主页。系统栏也可从屏幕边缘滑出。默认仅在沉浸且前台播放时保持亮屏，可在「主页歌词 → 沉浸观赏」关闭；打开设置、分享、切到后台或退出沉浸时恢复窗口状态。

滚动模式在 **主页歌词动效** 中调整缓动滚动、逐行错位、缩放和模糊。默认切行 800 ms、错位延迟 20 ms，缩放强度 75%、模糊强度 45%。连续短句切换时，滚动会承接当前速度，并逐渐减速。手动滑动歌词后暂停自动跟随 4 秒，点击歌词可跳转到对应时间。

主页和桌面歌词共用 14 天的歌词缓存；命中后直接复用，自定义歌词优先。缓存过期、歌曲时长明显不匹配或在主页手动重新获取时，才重新查询歌词源。

## 下拉快捷开关

进入 **设置 → 权限与开关 → 添加快捷开关**。Android 13 及以上可直接请求添加；旧版本在系统快捷设置的编辑页面添加「桌面歌词」。点击开关即可开启或关闭小窗，状态会跟随小窗的开启和关闭。缺少通知使用权或悬浮窗权限时，会打开应用的权限页面；授权后可以在那里开启，或返回快捷面板再次点击。锁屏时先解锁再操作。

## 歌词摘句与分享

长按主页歌词，或打开 **主页 ⋯ → 歌词摘句与分享**。可选择最多六句，选句按歌曲顺序排列；有译文时可选择是否附带。文字支持直接复制，卡片可预览、保存为 PNG 或通过系统分享面板发送。图片总内容限制为 1200 字，较长歌词会完整换行并增加图片高度；超出时需要减少选句。保存时选择文件位置，无需额外存储权限。

分享卡片用轻微模糊的专辑封面铺满背景，左上显示歌名和音乐人，中间居中显示歌词，右下放小应用图标；没有封面时使用深灰背景。

选句时会保留当时的歌名、歌手、封面和歌词，切歌后仍分享原来的内容。

## 本地逐字歌词导入

从 1.3.7 开始，自定义歌词编辑器支持普通 LRC、YRC 逐字歌词和已解码的 KRC 文本。选择「导入 .lrc / .yrc」，导入后保存即可；逐字轨道用于主页和悬浮歌词。

- **普通 LRC**：`[00:12.300]整句歌词`，只有逐行时间轴。
- **YRC / 项目内部逐字格式**：`[12300,600](12300,200,0)字(12500,400,0)词`；行标签是开始时间与持续时间，字标签是绝对开始时间与持续时间，单位均为毫秒。
- **解码 KRC 文本**：`[12300,600]<0,200,0>字<200,400,0>词`；字标签中的第一项是相对该行的偏移，导入器会转换为绝对时间。

原始加密 `.krc` 不是文本文件，需要先用 [KRC 转换工具](https://github.com/LuoH-AN/kugou-krc-tools) 解码或转换成 `.yrc`。JSON/CSV 是查看时间轴用的数据导出，不作为本应用的歌词导入文件。Enhanced LRC 的尖括号时间扩展不等同于 KRC/YRC，也不保证逐字导入。

导入后正文和逐字时间轴分别保存，不会把逐字标记当作歌词展示。修改某行正文或时间戳后，该行退回整句显示，未修改行尽量保留逐字数据。没有逐字时间的文件不会被人为补造逐字时间轴。

## 缓存歌词勘误

已经下载的歌词可以直接修改：播放当前歌曲时，打开主页 **⋯ → 修改当前歌词**；修改其他歌曲时，进入 **设置 → 歌词与翻译 → 缓存歌词勘误**，按歌名或歌手搜索已缓存的歌曲。

编辑器会载入歌词正文和已有译文，二者分别编辑。有时间轴时保留 LRC 时间戳，可以勘误文字、修改译文或调整时间；纯文本歌词也可以修改。未修改行的逐字数据会尽量保留，修改正文或时间戳的行使用整句显示。

点击保存后，会生成优先使用的自定义歌词，主页与桌面歌词都会应用修改。原始缓存保留；在自定义歌词管理中删除勘误版本，可以恢复自动匹配。已有自定义版本时直接打开它，避免覆盖之前的修改。缓存超过 14 天后仍可用于勘误，直到它被清除或因容量限制被淘汰。

## 字号、粗细和背景

入口：主页中控台 **⋯ → 设置 → 桌面歌词外观**。1.3.0 默认居中，柔白色 `#F4F6FA`、60% 半透明背景和 18 dp 圆角，渐变默认关闭；已有保存值继续优先使用。

- **歌词粗细**：默认 100%，范围 75%–225%，每档 25%；数值越大越粗，与字号独立保存。已有粗细设置保持不变。Android 8 的系统字体可用字重较少，相邻档位可能接近。
- **对齐方式**：左对齐、居中或右对齐，对原文、译文和上下文一起生效；长句仍可跟随播放横向移动。
- **歌词颜色**：拖动色盘自由选择颜色，也可调整色相、饱和度和明度，或输入 HEX 色值；确认应用后保存，取消不改变当前颜色。
- **渐变歌词**：启用后可自选起点（歌词颜色）与终点颜色，支持横向／纵向双色渐变。已有逐字时间轴的歌词保留逐字高亮；仅有逐行 LRC 或纯文本时显示整句渐变，不伪造逐字进度。并非任意平台的私有逐字格式都能直接导入。
- **悬浮窗宽度**：可在屏幕可用宽度的 40%–100% 之间调整。操作按钮在歌词上层，触摸后出现、拖动时隐藏，不为按钮预留额外宽度；位置锁定后先点锁按钮解锁再移动。
- **前文行数／后文行数**：分别选择当前歌词前后显示的行数，设为 0 时不显示该方向的上下文。
- **歌词预览**：与桌面歌词使用相同的外观配置，字号、粗细、对齐、渐变、上下文及翻译模式同步生效。预览里的英中歌词仅是样例，格子底纹用来观察透明度。
- **透明**：不绘制背景，直接透出下方页面；实际桌面歌词则透出桌面或其他应用。
- **半透明**：叠加底板，强度可调为 10%–90%。
- **不透明**：底板完全不透底。

半透明／不透明底板会根据歌词起点颜色选择深底或浅底，并使用细边线。圆角可在 0–32 dp 调整；透明模式没有底板或边线。

歌词不叠加文字阴影、光晕或描边。透明模式下，浅色字放在浅色背景上对比度较低；可以调整歌词颜色，或选择半透明／不透明背景提升可读性。

## “双语”与“补充翻译”有什么区别？

在 **设置 → 歌词与翻译 → 外语歌词** 中：

| 模式 | 显示内容 |
| --- | --- |
| 原文 | 只显示原歌词 |
| 双语 | 原歌词下方显示对应译文 |
| 中文 | 有译文时显示译文；缺译文时保留原文 |

**选择“双语”不会自动启用机翻。** 歌词源已有的译文可以直接显示，不需要配置翻译服务。没有译文时，仍会显示原文，而不是凭空生成中文。

## 缺少译文时怎么做？

进入 **设置 → 歌词与翻译 → 补充翻译**，选择一种补充方式：

1. **离线翻译**：先下载歌曲语种与中文所需的语言包，再启用离线方式。语言包下载需要可用网络，完成后翻译不需要向 API 发送歌词。
2. **API 翻译**：配置服务地址、模型和密钥并验证配置，再启用该方式。缺译文的歌词会发送到你选择的服务，可能产生服务费用。

返回主页即可应用，无需重启或重新开启桌面歌词。主页和桌面歌词都支持补充译文；平台已有的译文优先保留，只补缺少的行。已经是中文、没有歌词或尚未下载所需语言包时，不会出现预期之外的“双语结果”。

如果仍然只有原文，请先查看翻译状态：补充方式是否关闭、是否缺少语言包、API 是否配置完整、网络请求是否失败。不要把“选中双语显示”当成“翻译服务已准备好”。

## 存储与清理

系统设置显示的是安装后的应用、优化文件、用户数据和缓存占用，通常大于下载的 APK。离线翻译模型每个约 30 MB，下载后会额外占空间；不用的语言包可在补充翻译设置中删除。

补充译文的临时缓存按 4 MB、最多 1024 个文件和 30 天期限清理，容量估算会计入小文件的磁盘块开销。分享图片最多保留 8 张、约 16 MB，并在一天后清理；刚生成、正在分享的图片会保留。清理会在打开应用、开启小窗以及使用对应功能时执行。

**设置 → 关于应用 → 清理临时缓存** 可删除补充译文与分享图片，保留设置、自定义歌词和下载的语言包；已保存到自己选择位置的 PNG 不受影响。**歌词源管理 → 清除记录与缓存** 会同时清除匹配记录、新旧歌词缓存，保留自定义歌词与语言包。
