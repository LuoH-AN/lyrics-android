# 歌词外观与双语显示

## 主页歌词

入口：主页中控台 **⋯ → 设置 → 主页歌词**。可调整原文字号、翻译字号、字重、行间距和对齐方式，并查看文字预览；封面模糊背景默认关闭，可手动开启，开启后用铺满页面的封面图、柔和模糊与暗色遮罩衬托浅色歌词。原文字号为 16–48 sp，翻译字号为 12–32 sp，字重有细体到特粗六档，行间距为 0–28 dp。

在 **歌词显示模式** 中选择默认的「滚动」或「逐词跃动」。逐词跃动受 Folia 的逐词动画启发，当前句的词随演唱逐个跳出，按屏幕尺寸居中换行排版。点当前句可重听，长按仍可摘句分享。显示模式在设置中直接选择，舞台不再放置浏览或返回按钮。

逐词跃动需要歌词源的逐字时间轴。只有逐行 LRC、译文与原文文字不一致或逐字数据不匹配时显示整句，不估算演唱时间；纯文本歌词沿用滚动列表。特别长的句子限制独立动画数量，舞台显示整句并在必要时省略，完整正文保留在摘句分享中，也可在设置中切换为滚动模式查看。双语译文显示在舞台下方。镜头默认平滑跟随当前词的实际位置，移动整个歌词区域；开启封面背景后也使用同一镜头；开启系统或应用的「减少动效」时，显示稳定的当前句。

逐词跃动选中后，会显示专用自定义选项：逐词／逐字跳出、错落／居中／阶梯排版、四周飞入／向上跳出／原地弹出、入场时长、提前量、飞入距离、当前词放大、旋转、镜头方式与幅度、舞台呼吸以及整句切换方式。每项独立保存，可一键恢复默认参数，不定义主题。默认采用居中、向上跳出、600 ms 入场、150 ms 提前量、65% 距离、130% 当前词放大、零旋转、70% 跟随幅度、关闭呼吸与整句淡入淡出。逐字选项把一个有时间轴的词拆为完整字符后依次弹出；各字符保留词的真实起止时间，细小错位仅用于入场编排，未编造逐字演唱时间。

播放栏支持完整、紧凑和仅圆形封面三种形态，去掉底板和边框，竖屏恢复原宽度且不额外限高；横屏只限制左右宽度，完整栏占据上下可用高度。上下滑切换完整与紧凑；中等栏左滑缩到左下角封面，右滑把封面送到右下角。左侧封面向右滑、右侧封面向左滑，可拉回紧凑栏；长按也可展开。点封面暂停或继续播放，圆环显示进度。横竖屏使用相同手势，每次进入横屏默认缩成右下角圆形，返回竖屏恢复竖屏原来的大小与停靠方向。

滚动模式在 **主页歌词动效** 中调整缓动滚动、逐行错位、缩放和模糊。连续短句切换时，滚动会承接当前速度，并逐渐减速。手动滑动歌词后暂停自动跟随 4 秒，点击歌词可跳转到对应时间。

主页和桌面歌词共用 14 天的歌词缓存；命中后直接复用，自定义歌词优先。缓存过期、歌曲时长明显不匹配或在主页手动重新获取时，才重新查询歌词源。

## 下拉快捷开关

进入 **设置 → 权限与开关 → 添加快捷开关**。Android 13 及以上可直接请求添加；旧版本在系统快捷设置的编辑页面添加「桌面歌词」。点击开关即可开启或关闭小窗，状态会跟随小窗的开启和关闭。缺少通知使用权或悬浮窗权限时，会打开应用的权限页面；授权后可以在那里开启，或返回快捷面板再次点击。锁屏时先解锁再操作。

## 歌词摘句与分享

长按主页歌词，或打开 **主页 ⋯ → 歌词摘句与分享**。可选择最多六句，选句按歌曲顺序排列；有译文时可选择是否附带。文字支持直接复制，卡片可预览、保存为 PNG 或通过系统分享面板发送。图片总内容限制为 1200 字，较长歌词会完整换行并增加图片高度；超出时需要减少选句。保存时选择文件位置，无需额外存储权限。

分享卡片用轻微模糊的专辑封面铺满背景，左上显示歌名和音乐人，中间居中显示歌词，右下放小应用图标；没有封面时使用深灰背景。

选句时会保留当时的歌名、歌手、封面和歌词，切歌后仍分享原来的内容。

## 缓存歌词勘误

已经下载的歌词可以直接修改：播放当前歌曲时，打开主页 **⋯ → 修改当前歌词**；修改其他歌曲时，进入 **设置 → 歌词与翻译 → 缓存歌词勘误**，按歌名或歌手搜索已缓存的歌曲。

编辑器会载入歌词正文和已有译文，二者分别编辑。有时间轴时保留 LRC 时间戳，可以勘误文字、修改译文或调整时间；纯文本歌词也可以修改。未修改行的逐字数据会尽量保留，修改正文或时间戳的行使用整句显示。

点击保存后，会生成优先使用的自定义歌词，主页与桌面歌词都会应用修改。原始缓存保留；在自定义歌词管理中删除勘误版本，可以恢复自动匹配。已有自定义版本时直接打开它，避免覆盖之前的修改。缓存超过 14 天后仍可用于勘误，直到它被清除或因容量限制被淘汰。

## 字号、粗细和背景

入口：主页中控台 **⋯ → 设置 → 桌面歌词外观**。

- **歌词粗细**：默认 100%，范围 75%–225%，每档 25%；数值越大越粗，与字号独立保存。已有粗细设置保持不变。Android 8 的系统字体可用字重较少，相邻档位可能接近。
- **对齐方式**：左对齐、居中或右对齐，对原文、译文和上下文一起生效；长句仍可跟随播放横向移动。
- **歌词颜色**：拖动色盘自由选择颜色，也可调整色相、饱和度和明度，或输入 HEX 色值；确认应用后保存，取消不改变当前颜色。
- **渐变歌词**：启用后可自选起点（歌词颜色）与终点颜色，支持横向／纵向双色渐变。已有逐字时间轴的歌词保留逐字高亮；仅有逐行 LRC 或纯文本时显示整句渐变，不伪造逐字进度。并非任意平台的私有逐字格式都能直接导入。
- **悬浮窗宽度**：可在屏幕可用宽度的 40%–100% 之间调整。操作按钮在歌词上层，触摸后出现、拖动时隐藏，不为按钮预留额外宽度；位置锁定后先点锁按钮解锁再移动。
- **前文行数／后文行数**：分别选择当前歌词前后显示的行数，设为 0 时不显示该方向的上下文。
- **歌词预览**：与桌面歌词使用相同的外观配置，字号、粗细、对齐、渐变、上下文及翻译模式同步生效。预览里的英中歌词仅是样例，格子底纹用来观察透明度。
- **透明**：不绘制背景，直接透出下方页面；实际桌面歌词则透出桌面或其他应用。
- **半透明**：叠加底板，强度可调为 10%–90%。
- **不透明**：底板完全不透底。

半透明／不透明底板会根据歌词起点颜色选择深底或浅底，并使用细边线。圆角可在 0–32 dp 调整；透明模式没有底板或边线。

歌词不叠加文字阴影、光晕或描边。透明模式下，浅色字放在浅色背景上对比度较低；可以调整歌词颜色，或选择半透明／不透明背景提升可读性。

## “双语”与“补充翻译”有什么区别？

在 **设置 → 歌词与翻译 → 外语歌词** 中：

| 模式 | 显示内容 |
| --- | --- |
| 原文 | 只显示原歌词 |
| 双语 | 原歌词下方显示对应译文 |
| 中文 | 有译文时显示译文；缺译文时保留原文 |

**选择“双语”不会自动启用机翻。** 歌词源已有的译文可以直接显示，不需要配置翻译服务。没有译文时，仍会显示原文，而不是凭空生成中文。

## 缺少译文时怎么做？

进入 **设置 → 歌词与翻译 → 补充翻译**，选择一种补充方式：

1. **离线翻译**：先下载歌曲语种与中文所需的语言包，再启用离线方式。语言包下载需要可用网络，完成后翻译不需要向 API 发送歌词。
2. **API 翻译**：配置服务地址、模型和密钥并验证配置，再启用该方式。缺译文的歌词会发送到你选择的服务，可能产生服务费用。

返回主页即可应用，无需重启或重新开启桌面歌词。主页和桌面歌词都支持补充译文；平台已有的译文优先保留，只补缺少的行。已经是中文、没有歌词或尚未下载所需语言包时，不会出现预期之外的“双语结果”。

如果仍然只有原文，请先查看翻译状态：补充方式是否关闭、是否缺少语言包、API 是否配置完整、网络请求是否失败。不要把“选中双语显示”当成“翻译服务已准备好”。

## 存储与清理

系统设置显示的是安装后的应用、优化文件、用户数据和缓存占用，通常大于下载的 APK。离线翻译模型每个约 30 MB，下载后会额外占空间；不用的语言包可在补充翻译设置中删除。

补充译文的临时缓存按 4 MB、最多 1024 个文件和 30 天期限清理，容量估算会计入小文件的磁盘块开销。分享图片最多保留 8 张、约 16 MB，并在一天后清理；刚生成、正在分享的图片会保留。清理会在打开应用、开启小窗以及使用对应功能时执行。

**设置 → 关于应用 → 清理临时缓存** 可删除补充译文与分享图片，保留设置、自定义歌词和下载的语言包；已保存到自己选择位置的 PNG 不受影响。**歌词源管理 → 清除记录与缓存** 会同时清除匹配记录、新旧歌词缓存，保留自定义歌词与语言包。
