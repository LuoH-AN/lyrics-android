# 安装与常见问题

[返回项目首页](../../README.md) · [下载正式版](https://github.com/LuoH-AN/lyrics-android/releases/latest)

「桌面歌词」是一款独立歌词工具，不提供音乐播放服务，也不是录音识曲工具。歌曲仍在你常用的播放器里播放。

## 安装前确认

| 项目 | 要求 |
| --- | --- |
| 系统 | Android 8.0 及以上，无需 Root 或 LSPosed |
| 设备架构 | 当前 APK 仅支持 64 位 ARM（`arm64-v8a`），不提供 32 位 ARM 或 x86 包 |
| 显示组件 | 可用的 Android System WebView |
| 播放器 | 通过 Android MediaSession 提供歌曲信息；同步滚动还需要可用的播放进度 |
| 权限 | 通知使用权；使用悬浮歌词时还需要悬浮窗权限 |
| 网络 | 自动查询歌词、获取封面和检查更新需要网络；已有有效缓存或自定义 LRC 可供复用 |

## 第一次使用

1. 打开 [GitHub 最新正式版](https://github.com/LuoH-AN/lyrics-android/releases/latest)。展开 **Assets**，选择以 `arm64-v8a.apk` 结尾的文件。不要下载 `Source code (zip)` 或 `Source code (tar.gz)`，它们不能直接安装。
2. 安装 APK。如果 Android 提示不允许此来源安装，只对你用于下载或打开 APK 的应用按需授权，不必关闭系统整体安全防护。
3. 打开「桌面歌词」，按页面提示进入系统设置，找到本应用并授予**通知使用权**。这个权限与普通的“允许发送通知”不同。
4. 回到常用音乐播放器，播放一首歌，再回「桌面歌词」查看歌名和歌词。网络搜索可能需要等待，且不保证每首歌都有结果。
5. 需要在其他应用上方看歌词时，再授予**悬浮窗权限**，点主页控制栏「⋯」左侧的歌词按钮。权限引导页也提供「开启桌面歌词」。
6. 切到浏览器等应用确认小窗效果，拖到合适的位置。其他调整在「⋯ → 设置」中。

同签名正式版可覆盖升级。遇到签名冲突时，先核对旧版来源；不要为了升级直接卸载，卸载会删除本地设置和缓存，自定义歌词也需要提前保留。

## 权限与联网说明

以下是当前实现的简要说明，完整说明在应用内「设置 → 关于应用 → 隐私说明」。

| 权限或行为 | 用途与边界 |
| --- | --- |
| 通知使用权 | 访问播放器公开的 MediaSession，读取歌名、歌手、专辑、封面、播放状态与进度；当前通知监听实现不处理通知正文 |
| 悬浮窗权限 | 将歌词显示在其他应用上方，不代表能够绕过所有应用或系统界面的悬浮窗限制 |
| 前台服务与通知 | 保持用户主动开启的小窗；它们与用于访问媒体会话的“通知使用权”不是同一项权限 |
| 歌词、封面与别名查询 | 歌曲名称、歌手、专辑、时长等信息会按需发送到 LRCLIB、QQ 音乐、网易云音乐或 Apple iTunes Search API；这些服务可能记录 IP 地址、请求时间等常规信息 |
| 更新检查 | 访问 GitHub 获取版本信息 |
| 本地自定义 LRC | 保存在本机，不会作为文件上传到歌词平台；其中的歌词文本仍可能在主动启用 API 补充翻译时发送给翻译服务 |
| 离线补充翻译 | 默认关闭；语言包下载、更新及兼容性检查会联网，翻译输入与译文不发给翻译 API；ML Kit 也可能发送 API 性能与使用指标，参见 [ML Kit 条款](https://developers.google.com/ml-kit/terms) |
| API 补充翻译 | 默认关闭；启用后，缺少译文的歌词文本（包括来自自定义 LRC 的文本）会按需发送到你配置的 HTTPS 服务，数据处理与费用由该服务决定 |

应用不通过麦克风录音识曲，也不读取音乐文件内容。这里的“本地处理”和“离线翻译”不等于整个应用完全不联网。

## 常见问题

### 没有识别到正在播放的歌曲

- 确认授予的是**通知使用权**，不只是允许应用发送通知。
- 先让播放器实际播放一首歌，再回到本应用；暂停其他同时播放的应用后再试。
- 播放器必须通过系统媒体会话提供信息。如果它没有公开歌名、歌手或播放状态，单独授予权限不能补出这些数据。
- 记录播放器版本和系统版本后[提交反馈](https://github.com/LuoH-AN/lyrics-android/issues/new?template=bug_report.md)，不要只写“某播放器不支持”。

### 能看到歌名，但没有歌词或匹配到了错误版本

这与“没有识别到播放器”是两类问题。先检查网络、歌名和歌手信息，以及是否属于 Live、翻唱或不同发行版本；歌词平台未收录或接口暂时不可用也可能导致失败。

可在主页「⋯ → 歌词源管理」查看候选与版本，或在「设置 → 歌词与翻译 → 自定义歌词」导入自己的 LRC。主页与小窗对手动固定版本的使用仍有差异，详见[歌词搜索说明](lyrics-search.md#8-当前需要知道的限制)。

### 歌词提前、延后，或者不能逐字高亮

- 整体提前或延后，可在「设置 → 歌词同步」调整时间偏移。
- 时间差持续变化时，先确认歌曲和歌词是否为同一录音版本；仅调整整体偏移不一定能修复。
- 逐字高亮需要歌词自带逐字时间轴。普通 LRC 按整句显示，纯文本不能凭空产生同步时间轴。
- 点击歌词跳转、进度跟随等行为，也依赖播放器公开的进度与控制能力。

### 主页正常，但悬浮歌词不显示或过一会儿消失

- 确认已授予悬浮窗权限，并开启「桌面歌词」，而不只是打开应用主页。
- 先在桌面或浏览器测试；部分应用、敏感页面或系统界面可能限制其他应用悬浮显示。
- 小窗运行一段时间后消失时，检查**本应用**的后台省电限制。按需调整，不必关闭整台手机的省电或安全设置；具体选项因手机系统而异。
- 显示区域空白时，确认系统 WebView 可用；仍失败请提供截图与复现步骤。

### 选择了双语，为什么还是只有原文

“双语显示”不会自动开启机器翻译。歌词源有译文时可直接显示；没有时，需要主动下载语言包并启用离线翻译，或配置并启用自己的 API 翻译。详见[双语与补充翻译](lyrics-display.md)。

## 兼容性与反馈

**支持 Android MediaSession 是工作前提，不是所有播放器、机型和版本都已实测通过的保证。** 当前文档未列出经核实的跨播放器实测清单；不把未验证的播放器名称写成兼容承诺。

欢迎通过 [Issue](https://github.com/LuoH-AN/lyrics-android/issues/new?template=bug_report.md) 反馈。兼容正常的情况也可以反馈，以便逐步整理有依据的兼容记录。请包含：

- 「桌面歌词」版本、播放器名称与版本、手机型号、Android 及厂商系统版本。
- 是否识别歌曲、是否随切歌更新、主页是否同步、悬浮窗是否同步、切到后台后是否正常。
- 有问题时提供复现步骤、预期与实际表现；匹配问题补充歌名、歌手及 Live／翻唱等版本信息。
- 测试日期、必要的脱敏截图或短录屏，不要上传通知正文、账号信息、API Key 或完整个人日志。

单次测试结果只代表对应版本和设备条件，不应扩大为“所有设备都支持”。
