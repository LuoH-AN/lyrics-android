# 桌面歌词 1.3.0

新增逐词跃动显示，优化横竖屏操作、默认观感与应用体积。

- 逐词跃动支持真实歌词时间轴、词组排版、均衡换行、平滑镜头跟随与回中，并提前准备下一句。排版、入场、放大、镜头及间距可独立调整。
- 播放栏支持完整、紧凑和圆形封面三种形态；双向横滑可将封面收至对应角落。进入横屏时默认停靠右下角，竖屏保持原来的大小和位置。
- 新安装默认采用居中逐词显示、28 sp 原文、17 sp 译文及较轻的动效，保持背景稳定；应用使用低饱和蓝色并跟随系统明暗。桌面小窗默认居中、柔白文字及半透明背景。
- 加入酷狗音乐歌词源，改进 LRCLIB 的专辑、歌手和时长匹配及搜索回退。
- 裁剪字体、代码与资源，精简图标依赖，减小安装包；离线翻译与语言识别继续保留。
- 日常 CI 默认只生成安装包，不产出截图；完整 Android 检查按需开启。

升级保留已保存的自定义设置、歌词及语言包。需要使用新的逐词参数时，可在主页歌词设置中点击「恢复默认参数」。

安装包适用于 Android 8.0 及以上的 ARM64 设备，沿用正式包名和签名，可覆盖升级已有正式版。离线翻译语言包在启用对应功能时另行下载。
