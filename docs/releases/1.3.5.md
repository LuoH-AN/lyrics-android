# 桌面歌词 1.3.5

大字短语逐段呈现，加入跃动实时预览、动效方案和沉浸观赏。

- 长歌词按词组、标点和真实停顿分成小段；下一段进入时上一段自然退场，短段会适当放大，减少整屏文字挤小的问题。
- 修复「单行长度」调节经常不生效的问题，并让短语切换承接原来的镜头及文字动画。
- 长音在放大时增加轻微抖动，开始与结束平缓渐变；可在「长音抖动」中调节强度或关闭。
- 主页歌词设置新增无声实时预览，包含快句、长音和换段；支持固定在页面下方，边调参数边看效果。
- 提供「舒缓」「灵动」「强节奏」三套动效方案；可命名保存自己的跃动参数及字号、字重，最多 12 套，支持应用、覆盖保存和删除。
- 主页「更多 → 沉浸观赏」可隐藏系统栏与播放控件。轻触显示控制，播放时 4 秒后自动收起；返回键或「退出沉浸」退出。播放时保持亮屏可在主页歌词设置中关闭。

无逐词时间轴的歌词继续整句显示；歌词正文和原始演唱时间保留。从 1.3.1 升级时保留自定义参数，新功能无需恢复默认即可使用。

安装包适用于 Android 8.0 及以上的 ARM64 设备，沿用正式包名和签名，可覆盖升级已有正式版。
