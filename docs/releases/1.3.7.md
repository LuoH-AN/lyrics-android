# 桌面歌词 1.3.7

支持本地逐字时间轴导入。

- 自定义歌词编辑器新增 YRC 逐字歌词与解码后的 KRC 文本导入，保留每个字/词的开始时间和持续时间。
- 逐字文件自动分成普通歌词正文和逐字轨道，保存后用于主页和悬浮歌词；重新打开编辑时继续保留逐字数据。
- 导入普通 LRC 的方式不变。修改正文或时间戳的行退回整句显示，未修改行尽量保留原始逐字时间轴。

## 如何导入

在「自定义歌词」中选择「导入 .lrc / .yrc」，导入 `.yrc` 或解码后的 KRC 文本文件。原始加密 `.krc` 需要先解码，JSON/CSV 不作为歌词导入格式。

配套的 [酷狗 KRC 转换工具](https://github.com/LuoH-AN/kugou-krc-tools) 可在电脑上运行，生成普通 `.lrc` 和逐字 `.yrc`。逐字数据必须来自原始歌词，不估算或补造演唱时间。

普通 LRC 仍按整句显示；逐字高亮需要文件本身含逐字时间。此次改动只涉及本地导入，不改变自动酷狗歌词源仍以逐行 LRC 获取的方式。

升级保留现有设置、缓存和自定义歌词。安装包适用于 Android 8.0 及以上的 ARM64 设备，沿用正式包名和签名，可覆盖升级已有正式版。
