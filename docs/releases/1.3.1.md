# 桌面歌词 1.3.1

增强逐词跃动的节奏感，并支持高刷新率歌词动画。

- 文字与镜头同步跟随屏幕刷新，播放时优先请求 120 Hz，实际刷新率由设备和系统决定。
- 词组有更鲜明的大小层次，错落与阶梯排版采用不同的行宽和落点。
- 增强文字力度、放大和完整弹簧回弹，加入词组整体入场及当前词光晕。
- 镜头更及时地跟随密集歌词，短词的入场提前量随动画时长调整，唱后大小和颜色平滑回落。

升级后会一次性应用新的跃动参数，无需手动恢复默认；之后仍可在设置中自行调整。歌词数据、语言包与通用阅读设置保留。

安装包适用于 Android 8.0 及以上的 ARM64 设备，沿用正式包名和签名，可覆盖升级已有正式版。
