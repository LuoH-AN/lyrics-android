# 桌面歌词 1.3.8

酷狗 KRC 逐字歌词正式接入自动搜索。

- 酷狗来源优先获取 KRC：按歌名、歌手、录音版本和时长匹配歌曲，使用 hash 与 album_audio_id 查询逐字歌词。
- 自动下载并解码 KRC，保留真实逐字开始时间和持续时间，接入现有多源评分、共享缓存、歌词版本重选、主页与悬浮歌词。
- KRC 缺失、损坏或请求失败时回退普通 LRC；仍限制响应与解压大小，支持取消、候选去重，不伪造演唱时间。
- 沿用 HTTPS 接口和系统证书校验，不放开明文流量，不关闭证书校验。

无需手动运行脚本或导入文件。旧缓存不会强制清空；若升级后仍看到旧的逐行歌词，可在主页重新获取歌词，然后选择酷狗版本。是否能逐字显示仍取决于该录音的歌词是否提供有效逐字数据。

升级保留已有设置、缓存和自定义歌词。安装包适用于 Android 8.0 及以上 ARM64 设备，沿用正式包名与签名，可覆盖升级已有正式版。
