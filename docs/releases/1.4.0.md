# 桌面歌词 1.4.0

歌词匹配放宽：播放器或手动纠错只填写歌名时，也能找到同一歌手的现场版本。

- 例如「失语症 / 周深」可直接匹配音乐平台的「失语症 (Live)」，无需手动补全 Live 后缀。
- QQ、网易云、酷狗 KRC / LRC、LRCLIB 与歌曲身份补查使用一致的版本匹配规则。
- 缺少现场后缀不再直接排除候选；结合完整歌名、歌手和已知播放时长判断，优先同版本结果。
- 仍保留用户明确填写的版本要求，以及伴奏、纯音乐等类别判断；不会混合不同录音的逐字时间轴。
- 现场、現場、Live 等常见括号标记按同一歌名匹配。

保留 1.3.9 的歌名纠错记忆、恢复原名，以及主页和悬浮歌词同步。已有缓存不会批量清空；需要重新查找时，可在「更多」重新获取歌词或保存纠正歌名。

沿用正式包名与签名，可覆盖升级已有正式版。升级保留设置、自定义歌词和缓存。
