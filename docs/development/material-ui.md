# Material 原生界面

本次重构针对所有用户可见界面，不是仅替换设置页的几个按钮，也不是迁移到 Flutter。

## 组件与样式

设计以 [Agora 源码](https://github.com/newo-ether/Agora) 为准，具体映射见 [设计系统](../design-system.md)。默认使用 FOREST / Tonal Spot 的完整浅深色调色板、MiOutfit 字体、24/5dp 分组圆角、滚动收缩标题与弹簧面板。

设置页分为轻量分类入口和 8 个按需加载的分类；自定义歌词、同步记忆和歌词源列表使用 RecyclerView 复用可见行。按钮、开关、滑杆、输入框、弹窗与拖动行为均由原生 Material 组件承接。

主页中控图标保留 48dp 点击区域，悬浮窗选中态以服务回报为准。歌词颜色选择保留等宽等高的圆形色板。主题切换仅淡入新内容，不再创建全屏截图。

## 歌词与生命周期

主页不再用 WebView 绘制歌词或中控台。原生歌词模型、解析器、播放时钟和文本视图负责 LRC、逐字、翻译以及行切换；播放控制继续调用 Android MediaSession。歌词偏移只影响歌词，不改变播放进度条的音频时间。

主页切行沿用早期平缓动效的 900ms 统一缓动：滚动和轻微缩放使用同一曲线，逐行错位跟随，不叠加回弹或上下浮动。Android 12 及以上仅对更远的可见歌词施加原生模糊：与当前行相距 2 行起开始变糊（上下对称），越远越糊，当前句及前后各一句保持清晰；旧系统只使用缩放与透明度。触摸立即停止跟随并清除模糊，持续按住不会抢回滚动，抬手后等待 4 秒再恢复；点击歌词跳播则立即恢复跟随。动效强度可在设置的“主页歌词动效”中逐项开关并单独调数值：缓动滚动叠加时长滑杆（300–1500ms），逐行错位叠加延迟滑杆（0–120ms），行间缩放与远景模糊各叠加强度滑杆（0–200%），关掉效果后对应滑杆置灰。分组顶部内嵌一块预览区，用与主页同一个 `HomeLyricMotion` 驱动几行示例歌词自动逐行切换，改任意设置立刻按新样式静置。旧的三档设置（完整/精简/关闭）会自动迁移到对应开关组合。逐字高亮每帧只绘制当前句，跳播或强制重绘时会重刷所有行，已唱过的行保持全黑，未唱的行不会残留黑色。中控栏没有封面时显示占位音乐图标，使用完整居中缩放，不随容器纵横比裁切。

悬浮窗的可见歌词与关闭、锁定控件也使用原生视图。WindowManager、通知权限、悬浮窗权限、拖动与位置记忆仍由原服务负责。右侧控制条只在触摸后短暂显示，不再永久占用歌词宽度。

**本次没有重写全部歌词数据引擎。** 悬浮窗保留隐藏 WebView 承载既有匹配、候选历史、localStorage 缓存和翻译调度，以免 UI 重构改变用户保存的歌词版本。它只传递歌词数据，不参与可见界面的排版或动画；原生定期驱动数据引擎，不依赖隐藏网页的 requestAnimationFrame。HTML 中不可达的大窗、封面、播放控件、切源菜单与动态背景样式已删除，页面只保留数据引擎与紧凑渲染的回归测试代码。应用因此仍需要 Android System WebView。

这一区分意味着“可见 UI 全部原生”，不意味着“仓库中的 JavaScript 已全部删除”。以后如要完全移除 WebView，应另行迁移数据引擎并验证缓存和匹配行为，不能直接删除旧引擎。

## 验证

- Node 回归测试继续覆盖匹配记忆、过期响应和自定义歌词优先级。
- JVM 单元测试覆盖原生歌词解析、播放时钟与上下文数据规则。
- Robolectric 检查 Material 布局可创建、浅深色主题、小屏等宽圆形，以及图标按钮的等大、无边框和半透明选中状态。
- 编译与原生测试在 GitHub Actions 中运行；不在开发服务器运行 Gradle。

自动化检查不能替代真机视觉验收。安装测试 APK 后，仍需检查播放器切歌／拖动进度、授权取消、后台悬浮窗、长句逐字、颜色选择和系统字体缩放。
